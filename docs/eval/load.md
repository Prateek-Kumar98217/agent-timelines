# Load test

Each scenario ran for 90s on one laptop with the mock LLM at 0.5s per call and 4 worker processes, so this measures the platform and not any model. Latencies come from the stack's own metrics. Means are measured. Percentiles are estimated from coarse histogram buckets, so they can overstate: a 0.5s step can show a p95 near 1s. Generated by `loadtest/run.py`.
